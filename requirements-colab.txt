# SCOPE dependencies for Google Colab / Colab+
# Keeps Colab's preinstalled CUDA PyTorch/TorchVision and NumPy 2.x C-extension stack intact.
#
# Install on Colab with:
#   pip install -r requirements-colab.txt
#   pip install --no-deps compressai==1.2.8
#
# Why `--no-deps` for CompressAI 1.2.8?
# CompressAI 1.2.8 declares a legacy `numpy<2.0` cap on PyPI even though its PyTorch
# models and pybind11 C++ extensions (`compressai.ans`, `compressai._CXX`) do not use
# the NumPy C-API and run natively on NumPy 2.x. Installing its runtime/build deps
# below first and then `compressai==1.2.8` with `--no-deps` prevents pip from
# downgrading NumPy and breaking Colab's preinstalled OpenCV / SciPy / Pandas ABI.
